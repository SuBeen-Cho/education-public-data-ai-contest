# 고도화 미리보기 재설계 기획안

> **작성일**: 2026-05-30
> **목적**: 현재 설명 텍스트 위주인 "고도화 미리보기" 탭을 실제 작동하는 인터랙티브 데모로 재구성
> **대상 기능**: 제안 2(LLM 자동 룰 생성기) + 제안 4(이상 전파 추적)

---

## 1. 현황 문제점

| 항목 | 현재 | 문제 |
|------|------|------|
| 전체 형태 | 텍스트 설명 + 정적 박스 | "읽는 문서"이지 "쓰는 도구"가 아님 |
| 제안 2 | 자연어 예시 → Python 코드 블록 표시 | 입력할 수 없고, 결과가 고정됨 |
| 제안 4 | 의존성 그래프 텍스트 목록 | 트리/그래프 시각화 없음, 클릭 인터랙션 없음 |
| 전문 용어 | BFS, Chain-of-Thought, US 특허번호 노출 | 사용자(교육청 담당자) 대상 부적절 |

## 2. 재설계 방향

### 핵심 원칙
- **"보는 데모"가 아니라 "만져보는 데모"** — 클릭·입력·결과 확인이 가능해야 함
- **하드코딩 시나리오 기반** — 백엔드 호출 없이 프론트엔드만으로 작동
- **3단계 투명성** — 입력 → 중간 생성물 → 최종 결과를 단계별로 보여줌
- **Preview 배너** — 상단에 "미리보기 | 향후 구현 예정 기능입니다" 표시

### 참고 레퍼런스

| 패턴 | 레퍼런스 | 적용 방식 |
|------|---------|----------|
| 자연어→결과 | ThoughtSpot Spotter AI, Metabase Metabot | 검색창 + 추천 칩 → 3단계 결과 |
| 룰 빌더 폼 | ui-patterns.com Rule Builder | AI가 폼을 자동 채움 → 사용자가 조정 |
| 3단계 파이프라인 | Luzmo AI Dashboard | 입력→코드→시각화를 탭/스텝으로 분리 |
| 인과 그래프 | Cambridge Intelligence, Grafana Knowledge Graph | 노드 클릭 → 연쇄 하이라이트 애니메이션 |
| 트리 시각화 | D3.js Interactive Tree | 접기/펼치기 + 영향도 색상 |
| Preview 탭 | Saas UI Feature Flags, Stripe Progressive Disclosure | Preview 배너 + 인터랙션 가능 + 제출만 비활성 |

## 3. 제안 2 재설계: LLM 자동 룰 생성기

### 3-1. 화면 구성

```
┌─────────────────────────────────────────────────────┐
│ [Preview 배너] 향후 구현 예정 기능입니다              │
├─────────────────────────────────────────────────────┤
│                                                     │
│  "어떤 이상을 찾고 싶으신가요?"                       │
│  ┌─────────────────────────────────────────────┐    │
│  │ 검색창: 자연어 입력                           │    │
│  └─────────────────────────────────────────────┘    │
│  추천: [학생수 급감인데 교원 유지] [급식비만 급등]      │
│        [3년 연속 같은 값]  [전학률 이상]              │
│                                                     │
│  ─── 추천 클릭 또는 입력 후 ───                      │
│                                                     │
│  STEP 1          STEP 2           STEP 3            │
│  ┌──────────┐   ┌──────────┐    ┌──────────┐       │
│  │ AI 해석   │→  │ 룰 코드   │→   │ 예상 결과 │       │
│  │           │   │ (Python)  │    │ (탐지 수) │       │
│  └──────────┘   └──────────┘    └──────────┘       │
│                                                     │
│  [STEP 1] AI가 이해한 조건                           │
│  ┌─────────────────────────────────────────────┐    │
│  │ 대상 지표: 학생수(student_count)              │    │
│  │ 조건: 전년 대비 10% 이상 감소                  │    │
│  │ 추가 조건: 교원수(teacher_count) 변동 5% 이내  │    │
│  │ 위험도: 3 (자원 배분 영역)                     │    │
│  └─────────────────────────────────────────────┘    │
│                                                     │
│  [STEP 2] 생성된 Python 룰                          │
│  ┌─────────────────────────────────────────────┐    │
│  │ def check_custom_rule(df):                   │    │
│  │     student_yoy = ...                        │    │
│  │     teacher_yoy = ...                        │    │
│  │     return student_yoy < -10                 │    │
│  │            and abs(teacher_yoy) < 5           │    │
│  └─────────────────────────────────────────────┘    │
│  [임계값 조정] 학생 감소: [-10%] ▼  교원 안정: [5%] ▼ │
│                                                     │
│  [STEP 3] 42교 적용 결과 미리보기                    │
│  ┌─────────────────────────────────────────────┐    │
│  │ 탐지: 3건                                    │    │
│  │ ┌──────────────────────────────────────┐     │    │
│  │ │ 1. 수락고 2024  학생 -12.3%  교원 +1% │     │    │
│  │ │ 2. 상계고 2025  학생 -11.8%  교원 -2% │     │    │
│  │ │ 3. 불암고 2024  학생 -10.5%  교원 +3% │     │    │
│  │ └──────────────────────────────────────┘     │    │
│  └─────────────────────────────────────────────┘    │
│                                                     │
│  [기존 룰과 중복 체크]                               │
│  B1-2(학생 급변동 10%+)와 2건 중복 → 순수 신규 1건    │
│                                                     │
│  [룰 등록] (비활성 — Preview)                        │
└─────────────────────────────────────────────────────┘
```

### 3-2. 하드코딩 시나리오 (3개)

| # | 추천 칩 텍스트 | AI 해석 | 생성 코드 요약 | 탐지 결과 |
|---|--------------|---------|-------------|----------|
| 1 | "학생수 급감인데 교원 유지" | 학생 -10%+ AND 교원 ±5% | student_yoy < -10 and abs(teacher_yoy) < 5 | 3건 (수락고, 상계고, 불암고) |
| 2 | "급식비만 급등" | 급식비 +20%+ AND 학생 ±5% | meal_yoy > 20 and abs(student_yoy) < 5 | 4건 |
| 3 | "3년 연속 같은 값" | 3년 동일 수치 (E2-2와 유사) | vals[-3:] 전부 동일 | "기존 E2-2와 100% 중복 — 신규 룰 불필요" |

### 3-3. 인터랙션

1. 추천 칩 클릭 → 검색창에 텍스트 채워짐 + 3단계 결과 애니메이션 표시
2. STEP 2에서 임계값 슬라이더/드롭다운 조정 → STEP 3 결과 즉시 변경
3. 시나리오 3은 "중복 경고"를 보여줌 — 기존 룰과의 관계를 시각적으로 표현
4. "룰 등록" 버튼은 비활성 + "Preview — 향후 구현 시 활성화" 툴팁

### 4-2. 하드코딩 시나리오 (3개)

| # | 시나리오 | 근원 | 1차 전파 | 2차 전파 | 탐지 연쇄 |
|---|---------|------|---------|---------|----------|
| 1 | 압구정고 2025 학급수 급증 | 학급수 +23% | 학급당학생수, 교원1인당학생수 | C1-8, C1-7 | 1→3건 |
| 2 | 경기고 2025 학폭 피해 급증 | 피해학생 9명 | C3-3A 탐지 | B1-6 학폭심의 급증 | 독립 (전파 아님) |
| 3 | 당곡고 2024 급식비 급감 | 급식비 -76% | C2-3+ 탐지 | D2-1 유사학교 이탈 | 1→2건 |

### 4-3. 인터랙션

1. 시나리오 드롭다운 선택 → 그래프 애니메이션 (노드가 순차 점등)
2. 노드 클릭 → 해당 지표의 상세 수치 + 관련 룰 팝업
3. "감쇠 적용 전/후" 토글 → 점수 변화 실시간 표시
4. 시나리오 2는 "전파 아님 — 독립 사건"을 보여줌 (모든 이상이 연쇄는 아님)

## 6. 구현 범위

| 항목 | 방식 | 난이도 |
|------|------|--------|
| 추천 칩 → 검색창 채움 | JS onclick | 낮음 |
| 3단계 결과 표시 | JS 하드코딩 + CSS 애니메이션 | 중간 |
| 임계값 조정 → 결과 변경 | JS 하드코딩 (3시나리오 × 3임계값) | 중간 |
| 전파 그래프 | CSS flexbox/grid + JS 애니메이션 | 중간 |
| 노드 클릭 팝업 | JS 하드코딩 | 낮음 |
| 감쇠 전/후 토글 | JS 하드코딩 | 낮음 |

**외부 라이브러리 추가 불필요** — D3.js 없이 CSS + vanilla JS만으로 구현 가능 (노드 수가 적으므로)
