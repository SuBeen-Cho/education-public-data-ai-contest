## 1. 프로토타입 목표

### 시연에서 보여줘야 하는 것

기획서 p9~p11 (프로토타입 시연 3매)에 들어갈 **실제 동작 화면 스크린샷**.

| 시연 | 보여줄 것 | 페이지 |
|------|-----------|--------|
| 시연 1 | 자동 탐지 결과 대시보드 ("오늘의 3건") | p9 |
| 시연 2 | 개별 학교 상세 보고서 (룰셋 적용 결과 + 자연어 해석) | p10 |
| 시연 3 | 대화형 이상치 탐색 (자연어 질의 → 분석 → 보고서) | p11 |

### 프로토타입의 범위 (MVP)

```
[포함]
- 42교 x 3년 데이터 로드 및 전처리
- v3 룰셋 25개 자동 적용 (Python 룰 엔진)
- 우선순위 점수 산출 ("오늘의 3건")
- 자연어 질의 → LLM이 분석 계획 수립 → pandas 실행 → 결과 보고서
- HTML UI (대시보드 + 챗봇 인터페이스)

[제외]
- 실시간 데이터 수집 (미리 로드된 xlsx 사용)
- 사용자 인증/권한 관리
- DB 서버 (파일 기반, SQLite 또는 pandas 직접)
- 배포/호스팅 (로컬 실행)
```

            Rule("B1-1", "학생·교원 급변동", self.check_b1_1, star=2),
            # ... 25개 룰 전부
        ]

    def run_all(self) -> pd.DataFrame:
        """전체 룰 실행 → 탐지 결과 DataFrame 반환"""
        results = []

            hits = rule.check_fn(self.df)
            for hit in hits:

                    "school_code": hit["school_code"],
                    "school_name": hit["school_name"],
                    "year": hit["year"],

                    "rule_name": rule.name,

async def chat_explore(user_query: str, conversation: list, df: pd.DataFrame) -> dict:

    {conversation}

    [사용자 질문]
    {user_query}

    {{
        "analysis_plan": "분석 계획 설명",
        "columns_used": ["사용할 컬럼 목록"],
        "criteria": "적용할 수치 기준과 근거",
        "pandas_code": "실행할 pandas 코드 (df 변수 사용)",

    plan = await get_analysis_plan(plan_prompt)

**안전 실행 (핵심)**:
```python
def safe_execute_pandas(code: str, df: pd.DataFrame) -> pd.DataFrame:
    """LLM이 생성한 pandas 코드를 안전하게 실행"""
    # 허용 함수 화이트리스트
    ALLOWED = {'df', 'pd', 'np', 'groupby', 'filter', 'query',
               'describe', 'mean', 'median', 'std', 'quantile',
               'value_counts', 'sort_values', 'head', 'tail',
               'merge', 'concat', 'pivot_table', 'agg'}

    # 금지 패턴 (보안)
    BLOCKED = ['import', 'exec', 'eval', 'open', 'os.', 'sys.',
               'subprocess', '__', 'globals', 'locals', 'delete', 'drop']

    for blocked in BLOCKED:
        if blocked in code:
            raise SecurityError(f"금지된 패턴: {blocked}")

    # 읽기 전용 DataFrame 복사본에서 실행
    safe_df = df.copy()
    local_vars = {"df": safe_df, "pd": pd, "np": np}
    exec(code, {"__builtins__": {}}, local_vars)
    return local_vars.get("result", safe_df)
```

## 4. 기술 스택 상세

| 레이어 | 기술 | 이유 |
|--------|------|------|
| **백엔드** | Python 3.14 + FastAPI | 이미 설치됨, 비동기 지원, pandas 연동 |
| **데이터** | pandas + openpyxl | 이미 설치됨, xlsx 직접 로드 |
| **AI** | Anthropic API (Claude Sonnet 4.6) | 비용 효율 + 한국어 성능. 시연용이므로 Sonnet이면 충분 |
| **프론트** | 단일 HTML + CSS + vanilla JS | 디자인가이드 그대로 적용. 프레임워크 불필요 |
| **통신** | fetch API → FastAPI 엔드포인트 | 단순, 추가 의존성 없음 |

### 설치 필요 패키지

## 8. 대화형 탐색의 핵심 차별화 기능

### 8.1 도메인 지식 주입 (시스템 프롬프트)

일반 Text-to-SQL과 다르게, LLM에 교육 공시 도메인 지식을 사전 주입:

```python
SYSTEM_PROMPT = """
당신은 교육 정보공시 데이터 품질 분석 전문 어시스턴트입니다.

[도메인 지식]
- 데이터: 서울 42개 일반고(노원 17, 강남 13, 관악 12), 2023~2025년
- 소스: 학교알리미(KERIS), KESS(KEDI), NEIS(교육부)
- 핵심 관계: 학생수→학급수→교원수 (인과 방향)
- 기준일: 학생수=4/1, 교육통계=상반기4/1·하반기10/1

[정상 예외 16가지]
(v3 룰셋 1.5절 전문 삽입)

[내장 룰셋 요약]
(v3 룰셋 0절 요약표 삽입)

[출력 규칙]
- 절대 판정하지 마세요 ("오류다", "잘못이다" 금지)
- "검토 후보", "확인 권장" 표현만 사용
- 비교 시 동료군(같은 구, 같은 설립유형) 자동 적용
- 결과에 항상 신뢰도(높음/중간/낮음) 표시
- 정상 예외 해당 여부 자동 체크
"""
```

### 8.3 세션 기반 패턴 종합

대화가 이어지면 자동으로 맥락 패턴 감지:

```python
async def check_session_pattern(session_results: list) -> str:
    """세션 내 질문 결과들을 종합하여 MC 패턴 매칭"""
    # MC-1~MC-13 패턴과 비교
    patterns = {
        "MC-1": {"학폭", "교원", "학업중단"},
        "MC-4": {"학교회계", "법인회계", "교원"},
        "MC-11": {"코호트", "전출", "학폭"},
        # ...
    }
    detected_topics = set()
    for result in session_results:
        detected_topics.update(result["topics"])

    for mc_id, required_topics in patterns.items():
        if required_topics.issubset(detected_topics):
            return f"지금까지 탐색한 결과를 종합하면 {mc_id} 패턴과 유사합니다."
    return None
```
