# EduData Watch

**정보공시 자동 검증 · 이상치 탐지 시스템**

제8회 교육 공공데이터 AI 활용대회 출품작 (일반부문 — AI 활용 아이디어 기획)

## 프로젝트 소개

교육 정보공시 데이터의 항목 간 일관성, 시계열 맥락, 유사학교 비교 등을 자동 검증하여 검토가 필요한 항목을 탐지하는 시스템입니다.

기존 공시 검증 체계(입력 차단 + 연계 검증)가 다루지 못하는 **맥락 기반 검증 영역**을 보완합니다.

## 시스템 구조 — 3레이어 검증 모델

| 레이어 | 역할 | 담당 |
|--------|------|------|
| 1레이어 | 입력 시점 차단 (타입·범위·합산·필수값) | 기존 시스템 |
| 2레이어 | 자동연계 + 제출자료 검증 | 기존 시스템 |
| **3레이어** | **항목 간 맥락 일관성 · 시계열 급변동 · 유사학교 비교 · 미갱신 탐지** | **EduData Watch** |

## 핵심 설계 원칙

- **AI는 결론을 내리지 않는다** — 탐지와 정리만 수행하고, 판단은 인간 전문가에게 맡김
- **AI는 보조자** — 전문가를 대체하지 않고, 전문가가 도달할 수 없는 영역을 보완
- **룰 엔진 + LLM 결합** — Python 기반 업무규칙 엔진과 LLM 맥락 추론의 하이브리드 구조

## 기술 스택

- **룰 엔진**: Python (pandas, openpyxl)
- **맥락 추론**: LLM (프롬프트 기반 인터페이스)
- **데이터**: 학교알리미, KESS, NEIS 교육 공공데이터

## 활용 데이터

| 출처 | 설명 |
|------|------|
| [학교알리미](https://www.schoolinfo.go.kr/) | 학교현황, 교원현황, 급식비, 재정, 학교폭력 |
| [KESS](https://kess.kedi.re.kr/) | 학생수, 교원수, 학급수, 진학률 |
| [NEIS](https://open.neis.go.kr/) | 학교 기본정보 (설립유형, 학교유형) |
