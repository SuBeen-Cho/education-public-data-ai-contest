## 1. 멀티턴 referrer 미인식 — "2위는?" / "그럼 2위는?"

### 재현
```
사용자: 강남구 검토 우선도 1위 학교는?
챗봇:   경기고등학교 (지수 82.7, 강남구 1위) — 정상 priority 라우팅 ✓
사용자: 2위는?
챗봇:   "질문을 이해하지 못했습니다…" — fallback_help ❌
사용자: 그럼 2위는?
챗봇:   "질문을 이해하지 못했습니다…" — fallback_help ❌
```

### 원인 (추정)
- 백엔드 `app.py` 의 `_FOLLOWUP_REFERRERS` 패턴이 좁아 "2위는?", "그럼 2위는?", "다음은?", "옆은?" 같은 일반 follow-up referrer를 직전 priority 답의 후속으로 잡지 못함.
- priority 라우팅 후 멀티턴 history에 직전 컨텍스트가 저장돼도 그 컨텍스트를 이어가는 라우터(예: "2위" → priority + rank=2) 분기 부재.

### 영향
- 시연 화면 1·2(전국현황·학교목록)에서 발생 가능. 발표 데모에 "2위는?" 후속 질문 동선이 있으면 깨짐.
- 사용자 시연 흐름은 1위·top3 위주라 가능성 낮음. 그래도 발표 전 데모 리허설에서 동선 회피 권장.

### 추후 후보 조치
- `app.py` `_FOLLOWUP_REFERRERS` 에 `r"^[2-5]위(는|는\?)?$"`, `r"^그럼\s*[2-5]위"`, `r"^다음(은|은\?)?$"` 추가
- priority 라우팅 history에 `last_district` 보존 + follow-up 시 같은 district + rank=N 로 재조회
- 마감(2026-06-01) 후 시간 나면 처리

## 2. 지역 + 학생수 조합 → 0건 응답이 모호함

### 재현
```
사용자: 노원구에서 학생수가 줄어든 학교
챗봇:   "조건에 맞는 학교가 없습니다." — pandas_code 실행 결과 0건

사용자: 강남구에서 학생수가 줄어든 학교
챗봇:   "조건에 맞는 학교가 없습니다." — 동일

사용자: 학생수가 줄어든 학교 (지역 없이)
챗봇:   한광/대신/도선/청담/환일… 5교 결과 ✓ (강서·종로·성동·서초·중)
```

### 원인 (추정)
- 데이터 사실: 노원·강남 학교들엔 학생수 전년 대비 -10%+ 감소 학교가 실제로 0건이거나 임계값에 못 미침. **데이터 사실**이지 코드 회귀 아님.
- 그러나 응답이 단순 "조건에 맞는 학교가 없습니다."라 사용자가 시스템 결함으로 오해할 수 있음.

### 영향
- 신뢰도 낮춤 가능성. 시연에서 지역+조건 조합 입력이 발생하면 "왜 안 나오지" 느낌 줄 수 있음.

### 추후 후보 조치
- LLM 응답 템플릿에 지역·조건 명시 + "확인된 조건 안에서 0건" 명확화:
  - "노원구 일반고 17교 중 학생수가 전년 대비 10% 이상 줄어든 학교는 **없습니다**. 임계값을 5%로 낮추면 N건이 보입니다."
- 임계값 조정 follow-up chip 추가 (자가진단 chip 패턴 재활용)

## 3. 인사·잡담 변형 ("안뇽", "언농" 등) → 보고서 라우팅으로 잘못 떨어짐

### 재현 (screenshot 4)
```
사용자: 언농 (또는 안뇽 등 변형)
챗봇:   교육 정보공시 데이터 검토 보고서 (서울대사대부설고…) — route=llm 또는 pandas_code 결과 길게 출력 ❌
        (정상은: greeting 라우팅 → 인사 + 사용법)
```

### 원인 (추정)
- 백엔드 greeting 라우터의 키워드 매칭이 좁음 — "안녕"·"안녕하세요"·"hi" 정도만 잡고 변형/오타(안뇽·언농·하이요·왓숩)를 못 잡음.
- 매칭 실패 시 LLM 또는 pandas_code로 떨어져 무의미한 보고서가 길게 생성됨.

### 영향
- 시연 중 사용자가 인사 변형을 칠 일은 적음. 그러나 심사위원 질문 시 잡담성 입력이 들어오면 깨질 수 있음.

### 추후 후보 조치
- `app.py` greeting 라우터에 정규식 확장: `r"^(안녕|안뇽|언농|하이|hi|hello|hey)$"` + `r"^.{1,4}$"` 이고 한글이면 인사로 간주
- 또는 LLM 응답 첫 줄에 "질문 의도가 명확하지 않아 보고서 형식으로 답합니다…" 같은 가드 문구 추가
